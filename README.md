# Airborne Anchor Catch (Gate Catch)

A 2D co-op physics puzzle-action Flutter game where the **Light** dasher rockets mid-air through fast-closing security blast gates and catches an anchor just in time to tow the **Heavy** companion sliding underneath the door.

## Features
- **6 Progressive Lockdown Levels** with tripwire-triggered armored blast shutters, countdown timers, shock trenches, and cascading airlock chains.
- **Customization Studio (4 Options Per Selection):**
  - 4 Light Blitz Profiles, 4 Heavy Tow Slider Profiles, 4 Corridor Backgrounds (`Reactor Lockdown`, `Orbital Airlock`, `Vault Bunker`, `Cyber Tunnel`), 4 Towline Styles, and 4 Pilot Emblem Badges.
- **Solo Swap & 2P Local Split Controls** + Keyboard (`WASD` / `Arrow Keys` / `Space` / `Tab`).

## Run
Double-click `run_app.bat` or run:
```bash
flutter run -d chrome
```
